# MHCflurry 2.4.1

Documentation navigation cleanup and `datacache 1.35.0` test compatibility.
No runtime code, model weights, or predictions changed.

## Highlights

- **Cleaner documentation navigation:**
  - Moves the 8 internal training-pipeline specification pages out of the
    top-level sidebar and under `docs/maintainers.md`.
  - Aligns `docs/index.md` body sections with the Sphinx sidebar (grouping
    `dla_validation` under User guides).
  - Adds a curated **Public API overview** table at the top of `docs/api.md`
    before the full auto-generated module reference.
  - Adds `docs/changelog.md` to the Reference sidebar with links to per-version
    release notes.
  - Documents `MHCFLURRY_DATA_DIR`, `OPENVAX_DATA_CACHE`, and
    `OPENVAX_OFFLINE` / `DATACACHE_OFFLINE` in `docs/configuration.md`.
- **Test compatibility:**
  - Updates `test/test_downloads_cli_harmonize.py` to support both
    `datacache 1.35.0` (`platform_cache_dir`) and `datacache 1.34.x`
    (`_platform_cache_dir`).
