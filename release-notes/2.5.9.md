# MHCflurry 2.5.9

## What changed

- **First-class `mhcgnomes.AccessionedAllele` support across all vertebrate species:**
  - Updated `normalize_allele_name`, `normalize_sequence_resolved_allele_name`,
    and `allele_locus_name` in `mhcflurry/common.py` to accept sequence-backed
    Class I `mhcgnomes.AccessionedAllele` identifiers (introduced in
    `mhcgnomes >= 3.84` and emitted by `mhcseqs >= 2.14` for non-model
    vertebrates lacking official IPD-MHC nomenclature, e.g.,
    `TriakisScyllium-UAA*uniprot:O46817`, `OryziasLatipes-UBA*uniprot:H2LR16`,
    `Saha*uniprot:G3V1L5 class I`), while continuing to reject Class II
    accessioned alleles, forbidden `MIC`/`HFE` genes, pseudogenes, null/questionable
    alleles, and bare UniProt accessions.
  - Sequence-backed accessioned alleles now flow end-to-end through
    `build_pseudosequences_from_mhcseqs(normalize_alleles=True)`,
    `Class1AffinityPredictor.extend_alleles_from_mhcseqs()`, and
    `Class1AffinityPredictor.canonicalize_allele_name()`. Verified end-to-end
    against `mhcseqs 2.14.0` (`mhc-full-seqs.csv`): extending the `2.3.0`
    baseline with `--lock-existing` expands support from `20,205` alleles
    (`47` species) to **`26,156` alleles across `223` canonical vertebrate
    species** (`233` raw species labels, including **`2,884` `AccessionedAllele`s**
    and **`0` unparsed rows**).
- **Published speculative pan-class Class I → Class II experiment (`docs/experiment_25x_pan_class_ii.md`):**
  - Added a dated experiment report and publication-ready three-panel figure
    (`docs/_static/release-2.5.9/fig_pan_class_ii_experiment.svg`) to the
    Experiment Log (`docs/experiments.md`) testing whether 39-aa Class II
    binding-groove pseudosequences mapped via `mhcseqs` pan-class IMGT G-DOMAIN
    alignments transfer zero-shot on frozen Class I `2.3.0` weights across 15
    HLA-DR, HLA-DQ, and HLA-DP alleles (`7,500` quantitative 15-mer IC50 pairs)
    head-to-head against `NetMHCIIpan-4.3` (BA/EL) and an `HLA-A*02:01` negative
    control.
- **Dependency compatibility floors:**
  - Bumped `mhcgnomes>=3.87.2` (incorporating `AccessionedAllele` and the
    upstream fix for `pirl-unc/mhcgnomes#306` bare UniProt accession parsing)
    and optional `mhcseqs>=2.14.0` (canonical `AccessionedAllele` emission across
    all non-model vertebrate UniProt rows) in `pyproject.toml`.

## Compatibility

- Existing `2.3.0` model weights and predictions on previously supported alleles
  are unchanged.
