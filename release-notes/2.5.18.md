# MHCflurry 2.5.18

Documentation clarity, organization, and de-jargoning pass (**zero changes to
code, `2.3.0` weights, or predictions**).

## Highlights

- **Cleaner docs navigation (`docs/index.md`, `docs/experiments.md`):**
  - Separated everyday user guides from **Research & validation** (`whitepaper`,
    `dla_validation`, `experiments`) so new users find tutorials and recipes
    without wading through research benchmark reports.
  - Replaced run-on, jargon-heavy link summaries with concise 1–2 line
    plain-English descriptions.
- **Linked & explained companion tools everywhere:**
  - Every mention of [`mhcseqs`](https://github.com/pirl-unc/mhcseqs),
    [`mhcgnomes`](https://github.com/pirl-unc/mhcgnomes), and
    [`hitlist`](https://github.com/pirl-unc/hitlist) across `index.md`,
    `api.md`, `cross_species_validation.md`, `whitepaper_25x_cross_species.md`,
    `experiments.md`, and the `experiment_25x_*.md` logs now links to the
    repository and explains its role in plain English.
  - Updated `docs/configuration.md` so
    `MHCFLURRY_DEFAULT_CLASS1_PROCESSING_MODELS_DIR` accurately documents the
    presentation-bundle fallback.
- **Focused `docs/cross_species_validation.md` how-to guide:**
  - Refactored `cross_species_validation.md` into a concise, approachable user
    guide (defining *pseudosequence*, *mhcseqs*, and *pocket insertions* in
    plain English, showing Python & CLI recipes, and summarizing expectations)
    while pointing to `whitepaper_25x_cross_species.md` (and its PDF) for the
    full figures and tables — removing the 7-figure duplication across pages.
- **De-jargoned Web Whitepaper + rebuilt companion PDF:**
  - Added a **Companion Packages & Key Terms** primer table right up front in
    both `docs/whitepaper_25x_cross_species.md` and
    `docs/_static/whitepaper/mhcflurry_25x_cross_species_whitepaper.pdf`
    defining *pseudosequence*, *flanking sequences*, *AUROC / PPV@N*, *closed
    vs. open binding groove*, and *groove insertion* before using them.
