# MHCflurry 2.5.13

Documentation and empirical validation release adding the audited Cattle
`BoLA-I` and Dog `DLA-88` `hitlist` study to the `2.5.x` experiment log, with
**zero changes to `2.3.0` weights, code behavior, or predictions**.

## Highlights

- **Published audited Cattle `BoLA-I` & Dog `DLA` `hitlist` experiment
  ([`docs/experiment_25x_cattle_dog_hitlist.md`](../docs/experiment_25x_cattle_dog_hitlist.md)):**
  - Audits all Class I Cattle (`Bos taurus`) and Dog (`Canis lupus familiaris`)
    MS cohorts in the refreshed `hitlist` bundle (`2026-11-26`) against all
    three bundled `2.3.0` training tables (`811,134` affinity rows + `399,392`
    with-flank and no-flank processing rows), catching `100%` in-sample overlap
    on `hitlist` Dog `DLA-88*501:01`/`508:01` and IEDB PMID 36423003 `BoLA-I`
    cohorts (reinforcing `#490` and `docs/dla_validation.md`).
  - Evaluates `21,332` strictly peptide-disjoint flanked PXD008151 Cattle
    `BoLA-I` MS ligands across 3 cohorts against `10×` disjoint `Bos taurus`
    proteome decoys with symmetric real 5-aa flanks (`0.902–0.960` Presentation
    `+F` AUROC vs `0.628–0.789` `HLA-A*02:01` negative control; `+0.003` to
    `+0.006` AUROC and `+4.1%–4.2%` multi-allelic PPV@N lift from real bovine
    flanks).
  - Includes ultra-few-shot bovine allele ablations (`BoLA-3*002:01` with `12`
    training rows claiming `42.8%` of disjoint ligands and adding `+0.041` Aff
    / `+0.029` Pres `+F` AUROC; `BoLA-4*024:01` with `6` training rows reaching
    `0.904` Pres `+F` alone).
  - Adds publication-ready 3-panel SVG figure
    `docs/_static/release-2.5.13/fig_cattle_dog_hitlist_validation.svg`, links
    the report from `docs/experiments.md`, and cross-references it from
    `docs/dla_validation.md`.
- **First live validation of `#471` (`mode=light` CI) and `#359` (GitHub Actions
  Pages):** As a docs + version-only release, PR CI exercises the new fast
  `mode=light` path and publishes directly via `actions/deploy-pages@v5`.
