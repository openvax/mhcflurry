# MHCflurry 2.5.6

Bugfix release completing the remaining 11 issues from the codebase deep audit
(`#564`–`#569`, `#572`, `#575`, `#577`–`#579`), covering neural-network batch
normalization & merging, ensemble aggregation, percentile-rank calibration,
empty-input prediction, processing/proteome utilities, and `FastaParser`
hygiene. Existing `2.3.0` model weights and standard predictions are unchanged.

## Highlights

- **Neural network & ensemble fixes:**
  - `#564`: Fix `normalization='batch'` width inference and `batch_norm_early`
    wiring in `Class1NeuralNetwork`.
  - `#565`: Validate matching peptide/allele encodings before merging models in
    `Class1NeuralNetwork.merge()`.
  - `#566`: Fix `robust_mean()` edge cases for 2- and 3-model ensemble rows.
- **Affinity predictor, calibration & empty-input fixes:**
  - `#567`: Canonicalize allele keys in `calibrate_percentile_ranks()` and
    handle missing alleles cleanly in `percentile_ranks()`.
  - `#568`: Handle empty peptide inputs (`predict([])`,
    `predict_to_dataframe([])`) without crashing.
  - `#569`: Fix `pad_middle` edge behavior when padding width is zero.
  - `#577`: Guard histogram percentile-rank calibration against 0-bin and
    collapsed-logit edge cases.
- **Processing, presentation & FASTA fixes:**
  - `#572`: Fix PyTorch weight round-tripping in
    `Class1ProcessingModel.set_weights_list()`.
  - `#575`: Fix without-flanks-only prediction and `comparison_quantity`
    validation in `Class1PresentationPredictor.predict_sequences()`.
  - `#578`: Canonicalize non-canonical `excluded` alleles in
    `ProcessingProteome.sample()` and deduplicate `NumericCandidatePool`.
  - `#579`: Support repeated iteration, explicit UTF-8 encoding, and
    `pathlib.Path` inputs in `FastaParser`.
