# MHCflurry 2.4.0

Removes the deprecated legacy APIs, module wrappers, CLI aliases, and console
scripts that warned throughout the 2.3.x series (`2.3.26` and `2.3.28`).
Model weights, catalogue identities, and predictions are unchanged.

## Breaking removals

### Keras-era Python API aliases (#524)

| Removed | Use instead |
|---|---|
| `mhcflurry.common.configure_tensorflow` | `mhcflurry.common.configure_pytorch` |
| `Class1NeuralNetwork.keras_network_cache_key` | `Class1NeuralNetwork.model_cache_key` |
| `Class1NeuralNetwork.fit_generator` | `Class1NeuralNetwork.fit_streaming_batches` |
| `mhcflurry.data_dependent_weights_initialization.get_activations` | `get_activations_pytorch` |
| `worker_init(keras_backend=...)` | `worker_init(backend=...)` |

### Top-level compatibility wrapper modules (#505)

| Removed | Use instead |
|---|---|
| `mhcflurry.local_parallelism` | `mhcflurry.parallelism` |
| `mhcflurry.*_command` (11 top-level wrappers) | `mhcflurry.cli.*_command` |

### Duplicate top-level evaluation shortcuts (#512)

| Removed | Use instead |
|---|---|
| `mhcflurry compare-models` | `mhcflurry eval compare-models` |
| `mhcflurry plot-model-comparison` | `mhcflurry eval plot-comparison` |
| `mhcflurry paper-figures` | `mhcflurry eval paper-figures render` |

### Deprecated hyphenated console scripts (#526)

Removed `mhcflurry-calibrate-percentile-ranks`, `mhcflurry-class1-train-*`,
and `mhcflurry-class1-select-*` (along with `mhcflurry.cli.deprecated_scripts`).
Use the unified `mhcflurry <subcommand>` form instead.

`mhcflurry`, `mhcflurry-downloads`, `mhcflurry-predict`, and
`mhcflurry-predict-scan` remain installed and supported.
