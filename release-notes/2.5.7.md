# MHCflurry 2.5.7

Switches `downloads-generation/allele_sequences/GENERATE.sh` to build Class I
pseudosequence tables via `mhcflurry pseudosequences build --lock-existing`
(backed by `mhcseqs >= 2.12.5`), adds a hard post-build parity gate guaranteeing
zero character changes on every trained allele, and publishes the `hitlist`
cross-species Presentation-vs-Affinity validation figures and A/B training
parity results in the documentation. Existing `2.3.0` model weights and
predictions are unchanged.

## Highlights

- **Exact-lock pseudosequence builds (`--lock-existing`):**
  - Added `lock_existing=True` to `build_pseudosequences_from_mhcseqs()`,
    `extend_allele_to_sequence_from_mhcseqs()`,
    `Class1AffinityPredictor.extend_alleles_from_mhcseqs()`, and
    `mhcflurry pseudosequences build --lock-existing`.
  - Unlike `prefer_existing=True` (which upgrades `X`-containing entries),
    `lock_existing=True` freezes every existing entry verbatim and exempts
    locked alleles from `--max-x` filtering so previously trained alleles can
    never drift.
- **`downloads-generation/allele_sequences/GENERATE.sh` migrated to `mhcseqs`:**
  - Defaults to `MHCFLURRY_ALLELE_SEQUENCES_BACKEND=mhcseqs`, building both
    39-aa (`pseudosequences.mhcflurry.39aa.csv` / `allele_sequences.csv`) and
    34-aa (`allele_sequences.no_differentiation.csv`) tables via
    `mhcflurry pseudosequences build --lock-existing` in ~2 minutes without
    requiring `clustalo` or `wget`.
  - Runs the new `downloads-generation/allele_sequences/verify_trained_allele_parity.py`
    gate to enforce **0 missing alleles and 0 character differences** across
    every trained allele in `curated_training_data.csv.bz2` (verified 308/308
    bit-for-bit identical against `2.3.0`, adding `+2,704` net new named
    alleles).
  - Preserves `MHCFLURRY_ALLELE_SEQUENCES_BACKEND=legacy` for reproducing the
    historical `wget + clustalo + make_allele_sequences.py` pipeline.
- **Cross-species Presentation validation & dependency floors:**
  - Added the `hitlist` zero-shot Class I Presentation (+ real proteome flanks)
    versus Affinity validation figures (including Tasmanian devil marsupial MS
    elutions: `AUROC 0.749 → 0.806`, `PPV@N 0.273 → 0.356`), experimental
    `+/-` binding assays, and controlled A/B pan-allele training parity proof
    (`Max abs diff = 0.0`, `r = 1.0`) to `docs/cross_species_validation.md`.
  - Raised minimum dependency floors in `pyproject.toml` to `mhcgnomes>=3.79.0`
    and optional `mhcseqs>=2.12.5` (which resolves `pirl-unc/mhcseqs#139`–`#142`).
