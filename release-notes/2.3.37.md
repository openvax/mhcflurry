# MHCflurry 2.3.37

Repository packaging, tooling, CLI consistency, and unified ranking metrics.

## Highlights

- **Single `pyproject.toml` for packaging, Ruff, and pytest** (#507):
  Replaced `setup.py` and `.ruff.toml` with a PEP 621 `pyproject.toml`
  (`setuptools.build_meta`, dynamic version from `mhcflurry.version.__version__`,
  identical dependencies, console scripts, classifiers, and package data).
- **Added `test.sh`** (#507):
  Runs `python -m pytest` (preserving PyTorch MPS visibility on macOS) and
  forwards any CLI arguments directly to pytest.
- **Portable `develop.sh` in zsh and bash** (#485):
  Resolves the repository root using `${(%):-%x}` in zsh and `BASH_SOURCE[0]`
  in bash, verifies `pyproject.toml` is present before creating `.venv`, and
  installs from `"$SCRIPT_DIR"` rather than `.` so sourcing from a subdirectory
  no longer creates a stray `.venv`.
- **Moved release notes out of the repository root** (#508):
  Relocated `RELEASE_NOTES_*.md` to `release-notes/<version>.md` and updated
  release scripts, docs, and tests to read from `release-notes/`.

## Also included since 2.3.34

- **Unified PPV@N and ranking metrics** (`2.3.35`, #527): Added public
  `mhcflurry.ranking_metrics` (`ppv_at_n`, `ranking_metrics`) with the
  tie-invariant analytic expected-hits-within-ties rule across all CLI and
  training evaluation call sites; consolidated shared comparison helpers into
  `mhcflurry.cli.model_comparison_constants`.
- **Shared CLI flag helpers and `--allele`/`--alleles` aliases** (`2.3.36`, #504):
  Added `add_data_arg`, `add_models_dir_arg`, `add_hyperparameters_arg`,
  `add_out_arg`, and `add_alleles_arg` to `mhcflurry.cli_args`, and made
  `--allele` and `--alleles` interchangeable across all allele-accepting commands.

Model weights, catalogue identities, and predictions are unchanged.
