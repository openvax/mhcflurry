# MHCflurry 2.5.17

Unified **MHCflurry 2.5 Pan-Vertebrate & Pan-Class Whitepaper** (web +
publication-ready vector PDF) and automated **GitHub Container Registry
(`ghcr.io`)** multi-platform Docker release publishing. **Zero changes to
runtime code, `2.3.0` weights, or predictions.**

## Highlights

- **Unified Web Whitepaper + Accompanying Publication-Ready PDF:**
  - Published [whitepaper_25x_cross_species.md](https://openvax.github.io/mhcflurry/whitepaper_25x_cross_species.html)
    and its companion vector PDF
    [`mhcflurry_25x_cross_species_whitepaper.pdf`](https://openvax.github.io/mhcflurry/_static/whitepaper/mhcflurry_25x_cross_species_whitepaper.pdf)
    (reproducibly generated via `python docs/build_whitepaper_pdf.py` using
    `rsvg-convert` + `xelatex`), linked prominently from `README.md`,
    `docs/index.md`, `docs/experiments.md`, and `docs/cross_species_validation.md`.
  - Synthesizes all seven publication vector figures and tables across the
    `2.5.x` empirical program: taxonomic expansion (`47 → 223–231` vertebrate
    species, `+184` net new species across 14 clades), zero-shot Class I
    Affinity & Presentation (+ real species proteome flanks) across `16`
    unseen-species/pocket-mutant cohorts, empirical vs. zero-shot sequence
    motifs and the Bat `Ptal-N*01:01` `+3aa MDL` failure mode, bit-identical
    `--lock-existing` pan-allele training parity (`Max |Δ| = 0.0`,
    `r = 1.000000`), audited three-table overlap & strictly peptide-disjoint
    Cattle `BoLA-I` (`21,332` flanked MS ligands, `0.902–0.960` AUROC) / Dog
    `DLA-88` validation, and the exploratory zero-shot Class I → Class II
    structural boundary study against `NetMHCIIpan-4.3`.
- **Automated Multi-Platform GHCR Docker Publishing (`#498`, `#467`):**
  - Updated `.github/workflows/docker.yml` to publish tested `linux/amd64` and
    `linux/arm64` images automatically to `ghcr.io/openvax/mhcflurry:<version>`
    and `:latest` on every stable release using built-in `GITHUB_TOKEN`, while
    cleanly gating Docker Hub (`openvax/mhcflurry`) push on
    `DOCKERHUB_USERNAME`/`DOCKERHUB_TOKEN` secret presence so release workflows
    no longer fail when Docker Hub credentials are unset.
  - Updated `docs/docker.md` to document `ghcr.io/openvax/mhcflurry:latest`
    alongside Docker Hub mirroring.
- **Issue hygiene:** Closed `#513` (stack-baseline alignment complete; Sphinx
  intentionally retained for live `doctest`/`programoutput`/`autoprogram`
  coverage) and `#381` (already fixed in `affinity_candidate_figures.py` via
