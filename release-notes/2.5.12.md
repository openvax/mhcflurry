# MHCflurry 2.5.12

CI and GitHub Pages workflow modernization with **zero changes to `2.3.0` weights
or predictions**.

## Highlights

- **Change-classified CI for docs/container-only PRs (#471):**
  - Added [`scripts/classify_ci_changes.py`](../scripts/classify_ci_changes.py)
    and a fast `classify` job in `.github/workflows/ci.yml` that distinguishes
    docs/container/release-notes/version-only PRs (`mode=light`) from PRs
    touching runtime Python code, `downloads.yml`, dependencies, tests, scripts,
    or CI gates (`mode=full`).
  - `mode=light` PRs still run shell syntax linting (`bash -n`), `./lint.sh`,
    and packaging/CLI/classifier tests on Python 3.11 while keeping all four
    `CI/build (3.11–3.14)` check names consistently reported and recording the
    skipped ML matrix reason in `$GITHUB_STEP_SUMMARY`.
  - All `push` events to `master`, empty/unresolvable diffs, and any PR
    modifying package/test/dependency/catalogue files fail safe to `mode=full`.
- **Migrated GitHub Pages to GitHub Actions Pages (#359):**
  - Replaced `peaceiris/actions-gh-pages` branch pushes in
    `.github/workflows/docs.yml` with `actions/configure-pages@v6`,
    `actions/upload-pages-artifact@v5`, and `actions/deploy-pages@v5` so
    documentation publishes directly without triggering GitHub's legacy
    Node 20 `pages-build-deployment` branch workflow.
  - Preserves `previous-versions/` archived documentation from `gh-pages` and
    prevents `master` deployments from being cancelled by concurrent runs.
- **Stale-issue triage:** Verified and closed already-resolved issues `#406`
  (API reference RST rendering + `api_coverage.py` gate), `#409` (processing
  training completion log), and `#361` (pinned Ruff 0.16.0 rule config).
