# MHCflurry 2.5.0

Adds `mhcseqs`-backed Class I binding-groove pseudosequence extraction that
strictly generalizes MHCflurry's existing 39-aa (and NetMHCpan 34-aa)
pseudosequence pipeline without requiring external `clustalo` or Biopython
installations. Model weights (`2.3.0`) and predictions on existing alleles are
unchanged.

## New features

- **`mhcseqs`-backed Class I pseudosequence extraction
  (`mhcflurry.mhcseqs_pseudosequences`, re-exported from
  `mhcflurry.pseudosequences`):**
  - `extract_class1_pseudosequence(sequence, length=39|34, ...)` and
    `extract_class1_pseudosequence_with_alignment(...)` decompose arbitrary
    full-length, mature, or partial Class I MHC protein sequences via
    `mhcseqs.decompose_domains(..., mhc_class="I")` (including optional
    mature-numbered point mutations such as `mutations=("W167S",)`), extract
    the pinned 39-aa MHCflurry or 34-aa NetMHCpan binding-groove positions,
    and emit clear diagnostic warnings when internal groove insertions (e.g.
    bat `Ptal-N*01:01` `MDL`) are omitted or when requested mutations do not
    alter any pseudosequence position.
  - `extract_class1_pseudosequence_from_grooves(groove1, groove2, length=39|34)`
    delegates to `mhcseqs.align_domain_to_imgt` when `mhcseqs >= 2.9.0` is
    installed (with a built-in BLOSUM62 semi-global affine-gap Gotoh fallback
    against `HLA-A*02:01` α1/α2).
  - `build_pseudosequences_from_mhcseqs(...)` and
    `extend_allele_to_sequence_from_mhcseqs(...)` generate full Class I
    pseudosequence tables directly from `mhcseqs` or strictly generalize an
    existing table while preserving previously supported non-`X` alleles
    verbatim (`prefer_existing=True`).
- **`Class1AffinityPredictor` runtime helpers:**
  - `predictor.add_allele_from_sequence(allele, protein_sequence, ...)`
    registers a novel allele or point mutant from its protein sequence.
  - `predictor.extend_alleles_from_mhcseqs(...)` strictly generalizes a loaded
    pan-allele predictor's `allele_to_sequence` table from `mhcseqs`.
- **CLI subcommands under `mhcflurry pseudosequences`:**
  - `mhcflurry pseudosequences extract --sequence ... [--allele ...] [--mutation ...] [--length 39|34]`
  - `mhcflurry pseudosequences build [--mhcseqs-csv ...] [--existing-csv ...] [--prefer-existing] [--out ...]`
- **Cross-species validation & publication figures (`docs/cross_species_validation.md`):**
  - Adds publication-ready SVG figures (`docs/_static/release-2.5.0/*.svg`) and a
    reproducible benchmark script (`scripts/benchmark_cross_species_mhcseqs.py`)
    evaluating frozen `2.3.0` weights zero-shot across newly supported
    vertebrate clades (marsupials `Trvu-UB*01:01` AUROC 0.852 across 5,607 MS
    ligands and `Saha` 0.764; felines `FLA-K*007:01` 0.880, `FLA-E*003:01`
    0.830 across 1,612 MS ligands, `FLA-E*018:01` 0.978; birds `Anpl-UAA*01`
    0.894, `Anpl-UAA*76` 0.824; binding-pocket mutants `SLA-1*04:01 R156A` and
    `FLA-E*018:01 W167S`), alongside honest groove-insertion failure-mode
    analysis (`Ptal-N*01:01` `+3aa MDL` A-pocket insertion).
- **Packaging:**
  - Adds optional extra `mhcseqs = ["mhcseqs>=2.9.0"]` in `pyproject.toml`.
  - Updates `README.md`, `docs/intro.md`, `docs/index.md`, `docs/api.md`,
    `docs/changelog.md`, and `notebooks/mhcflurry-colab.ipynb` for the 2.5
    series.
