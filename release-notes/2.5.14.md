# MHCflurry 2.5.14

Repository hygiene and experiment-provenance organization release, with **zero
changes to runtime Python code, `2.3.0` weights, or predictions**.

## Highlights

- **Pruned 15 dead scripts and ancient LSF/TensorFlow fossils:**
  - Deleted 7 unreferenced one-off `2.3.0` campaign scripts from
    `scripts/training/` (`benchmark_processing_sampler.py`,
    `benchmark_training_profile.py`, `collate_experiment_figures.py`,
    `full_ensemble_minibatch_sweep.sh`, `plot_minibatch_sweep.py`,
    `render_release_experiment_paper_figures.py`,
    `summarize_processing_ensemble.py`).
  - Removed 8 historical Mount Sinai LSF cluster submit headers
    (`downloads-generation/*/cluster_submit_script_header.mssm_hpc*.lsf`) that
    invoked legacy `tensorflow` GPU probes.
- **Quarantined recorded experiment campaigns under `scripts/experiments/`:**
  - Moved the 14 self-contained `2.3.0` experiment scripts (affinity factorial
    sweep + training-stop summary, processing regularization/activation sweep,
    flank ablation, fold-ensemble, and subset diagnostics) into
    `scripts/experiments/release_2_3_0/` and moved
    `benchmark_cross_species_mhcseqs.py` into
    `scripts/experiments/release_2_5_0/`.
  - Added [`scripts/experiments/README.md`](../scripts/experiments/README.md)
    indexing every recorded experiment script to its corresponding doc/note and
    test suite.
  - Updated relative paths in moved shell scripts, tests, and
    `docs/cross_species_validation.md`.
- **Fixed stale README CLI documentation:** Removed references to nonexistent
  subcommands (`mhcflurry train pan-allele-release`,
  `mhcflurry eval release-experiment-figures`, `scripts/dev/`) from
  `scripts/README.md`, `scripts/training/README.md`, and `experiments/README.md`.
- **Issue tracker triage:** Closed 26 verified already-fixed or superseded
  issues (including `#257` `H2-Dq` support verified live on `2.5.13`, `#268`,
  `#314`, `#368`–`#373`, `#375`, `#377`–`#379`, `#383`, `#397`, `#399`–`#404`,
  `#407`, `#410`, `#431`), bringing open issues from 68 down to 42.
