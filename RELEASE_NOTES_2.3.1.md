# MHCflurry 2.3.1

Prediction help is easier to scan: short usage lines, concise examples,
input-first option groups, bounded text width and whitespace between options.
The top-level and prediction help screens use subtle colors in terminals;
redirected help stays plain text, and `NO_COLOR=1` disables color.

The command reference now explains how to inspect downloaded models and compare
weight bundles on the same input rows. Command names, flags and prediction
behavior are unchanged. This package uses the released 2.3.0 weights.
