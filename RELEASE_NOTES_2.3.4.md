# MHCflurry 2.3.4

Download discovery uses compact tables again. Affinity, processing and
presentation appear first, with latest weights, other available versions and
installed catalogue directories. Historical models and supporting data follow.

Headings and status columns use restrained terminal color, respecting
`NO_COLOR`, `TERM=dumb` and redirected output. Detailed descriptions remain in
`downloads info NAME`; `downloads --verbose info` shows all model paths and
environment overrides. Machine-readable JSON is unchanged.

The default weights remain **2.3.0**. Prediction code and models are unchanged.
