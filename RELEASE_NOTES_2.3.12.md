# MHCflurry 2.3.12

This documentation-only release removes filler from the user guides. Library
behavior, model weights and predictions are unchanged; default weights remain
2.3.0.

- Removed sentences that only reassured readers ("most users…"), described the
  page itself, restated a heading, or repeated a nearby sentence, across the
  landing page, tutorials, guides, references and maintainer pages.
- The Python tutorial's scanning example now correctly describes its inputs as
  protein sequences.
