# MHCflurry 2.3.12

Not published separately; its changes ship in 2.3.13.

This documentation-only change removed filler from the user guides. Library
behavior, model weights and predictions are unchanged; default weights remain
2.3.0.

- Removed sentences that only reassured readers ("most users…"), described the
  page itself, or repeated a nearby sentence.
- Added an Advanced topics list to the landing page and renamed "Processing
  training data" to "Antigen-processing training data" in `training.md`.
- The Python tutorial's scanning example no longer calls its protein sequences
  "peptide sequences".
