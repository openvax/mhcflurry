# MHCflurry 2.3.3

Installation guidance now consistently refers to **MHCflurry 2.3** and uses
`mhcflurry>=2.3,<2.4` to install stable patch releases. This fixes contradictory
version labels in the README and Colab setup and keeps future patch updates
from making the installation instructions stale.

Exact weight-release and evaluation identifiers remain unchanged. The default
weights are **2.3.0**; this documentation correction does not change prediction
code or models.
