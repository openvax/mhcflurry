Release notes and changelog

MHCflurry separates code versions (published on PyPI) from weight catalogue releases (such as 2.3.0 and 2.2.0; see Downloading and selecting model weights). Full per-version notes live in the repository’s release-notes/ directory and on GitHub Releases.

2.5 series (current)

  • 2.5.11: Codebase cleanup and modularization (#506, #419, partial #513): splits legacy Keras config/weight loading out of class1_neural_network.py into mhcflurry/keras_model_config.py, breaks fit() and fit_streaming_batches() into standalone-tested phase helpers in mhcflurry/class1_training.py, removes the deprecated dense-vector encoding remnants (FlankingEncoding.vector_encode/encode, EncodableSequences.variable_length_to_fixed_length_vector_encoding, and Class1NeuralNetworkModel(peptide_input_is_indices=False)), and drops the undeclared optional pyarrow CSV engine fallback in pan-allele training. Verified bit-identical (179/179 arrays, max_abs_diff=0.0) against 2.5.10 across released 2.0.0/2.2.0/2.3.0 models and deterministic training.

  • 2.5.10: CLI UX polish across prediction, downloads, training/selection/calibration, and pseudosequences (#424–#428): adds --float-format and documents units on predict/predict-scan, eliminates duplicated flank columns and inconsistent processing-only scan columns, silences noisy default repr/plan/ unused-key logs, replaces routine user-error tracebacks with one-line CLI errors, fixes train/select/calibrate --help usage synopses and stray SIGUSR1 banners, and fixes downloads --verbose/--quiet and subcommand help. Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.9: Adds first-class mhcgnomes.AccessionedAllele support in mhcflurry/common.py so all 2,884 sequence-backed non-model vertebrate Class I alleles from mhcseqs 2.14.0 (e.g., TriakisScyllium-UAA*uniprot:O46817, Saha*uniprot:G3V1L5 class I) flow cleanly through normalize_allele_name, build_pseudosequences_from_mhcseqs(normalize_alleles=True) (26,156 alleles across 223 canonical vertebrate species with 0 unparsed rows), and Class1AffinityPredictor; publishes the speculative pan-class Class I → Class II transfer experiment against NetMHCIIpan-4.3 in Experiment 2026-11-25: Speculative pan-class Class I → Class II transfer via mhcseqs IMGT alignments (Experiment log); and bumps mhcgnomes>=3.87.2 / optional mhcseqs>=2.14.0. Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.8: Adds the published Experiment log log and full 2.5.x cross-species hitlist + IEDB validation experiment report (Experiment 2026-11-25: Cross-species hitlist validation & mhcseqs training parity) with a new 16-cohort groove-specificity & training-parity synthesis figure, and defensively guards build_pseudosequences_from_mhcseqs(normalize_alleles=True) against bare UniProt accessions being misparsed as MHC alleles (pirl-unc/mhcgnomes#306). Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.7: Adds --lock-existing / lock_existing=True to freeze baseline alleles verbatim, switches downloads-generation/allele_sequences/GENERATE.sh to mhcflurry pseudosequences build --lock-existing with a hard 0-diff parity gate on all trained alleles (verify_trained_allele_parity.py), adds the hitlist zero-shot Presentation-vs-Affinity validation figures to Cross-species alleles, pseudosequences, and zero-shot validation, and bumps mhcgnomes>=3.79.0 / mhcseqs>=2.12.5. Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.6: Fixes Class1NeuralNetwork batch normalization & merging (#564, #565), robust_mean (#566), percentile-rank calibration & empty-input prediction (#567–#569, #577), Class1ProcessingModel / predict_sequences / ProcessingProteome (#572, #575, #578), and FastaParser (#579). Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.5: Fixes training-loop, RandomNegativePeptides, ppv_at_n, compare-models, allele-specific model selection, and predict / predict-scan / downloads CLI edge cases (#588–#595). Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.4: Fixes local parallelism, GPU/batch auto-sizing, torch.compile, and cluster retry bugs (#580–#587), accepts registered custom non-mhcgnomes allele keys in AlleleKeyResolver (#597), and guards mhcseqs >= 2.12.2 fragment statuses (status="short", alpha1_only, alpha2_only, fragment_fallback). Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.3: Fixes 2.5.x regressions (#550–#555), NumPy 2 / Pandas 3 compatibility crashes (#556–#559), and core affinity/processing/presentation bugs (#560–#563, #570, #571, #573, #574, #576). Existing 2.3.0 weights and predictions are unchanged.

  • 2.5.2: Adds a torch-free fast path for --list-supported-alleles and --list-supported-peptide-lengths in mhcflurry predict and mhcflurry predict-scan, suppresses duplicate WARNING logs when Class1AffinityPredictor raises under throw=True (#443), and sets explicit default timeout=60s and max_retries=3 in install_download (#462). Existing weights and predictions are unchanged.

  • 2.5.1: Migrates mhcflurry downloads fetch onto datacache>=1.37.0 (install_archive / inspect_archive) with pinned 2.3.0 SHA-256 checksums and byte sizes, --force refresh/repair, downloads info --verify, read-only legacy directory preservation, and portable_names support for historical POSIX tarballs (#484). Existing weights and predictions are unchanged.

  • 2.5.0: Adds mhcseqs-backed Class I binding-groove pseudosequence extraction (mhcflurry.pseudosequences, Class1AffinityPredictor.add_allele_from_sequence, extend_alleles_from_mhcseqs, and mhcflurry pseudosequences extract|build), delegating to mhcseqs >= 2.9.0 IMGT G-DOMAIN alignment with groove-insertion and no-op-mutation diagnostic warnings. Includes zero-shot cross-species validation benchmarks and figures (Cross-species alleles, pseudosequences, and zero-shot validation). Existing 2.3.0 weights and predictions are unchanged.

2.4 series

  • 2.4.1: Documentation navigation cleanup (moves internal training-recipe notes under Maintainer workflows, adds a public API overview to API Documentation, adds this release-notes page, and documents OPENVAX_DATA_CACHE / OPENVAX_OFFLINE in Configuration and performance), plus datacache 1.35.0 test compatibility.

  • 2.4.0: Removes deprecated Keras-era Python API aliases, legacy top-level mhcflurry.*_command module wrappers, duplicate mhcflurry evaluation shortcuts, and deprecated hyphenated training/selection/calibration console scripts. Keeps 2.3.0 model weights and predictions unchanged.

2.3 series

  • 2.3.38: Harmonizes the data cache and downloads CLI on datacache>=1.34.0 (OPENVAX_DATA_CACHE, OPENVAX_OFFLINE, mhcflurry downloads dirs, mhcflurry downloads prune, and mhcflurry downloads path --json) while preserving existing legacy cache directories.

  • 2.3.0: PyTorch-native rewrite, updated 2.3.0 presentation/affinity/processing weights (see Evaluation of the 2.3.0 weights), automatic GPU/CPU workload planning, unified mhcflurry CLI, and compact percentile calibration.

Earlier releases

  • 2.2.0 / 2.1.x / 2.0.x: MHCflurry 2.0 pan-allele binding and antigen processing models (weights remain available via --model-release 2.2.0).
